## Typography
- All text: **Segoe UI / Helvetica Neue / Arial** (system sans-serif)
- Headlines: weight 900, tracked tight
- Body: weight 400–600

## Animation Principles
- **Spring physics** for all entries (stiffness 140–300, damping 18–22)
- **Typed-on** cursor effect with blinking `|` at active position
- **Cross-fade** 15 frames between every scene transition
- **Count-up** numbers for stats (0 → target over ~50 frames)
- **Pulse / breathe** on interactive elements (CTAbutton, badge)
